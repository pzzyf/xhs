# P3：oRPC 契约 + 双列信息流 + 详情（只读）

> 目标：`packages/api` 契约定稿；Server 实现 `notes.list/get`；Native 双列瀑布流 + 无限滚动 + 详情页，连真实 D1 种子数据。
> 结束标志：首页双列流展示 ≥16 条种子（分页加载），点卡片进详情见大图/标题/正文/作者/赞计数（只读，未登录可见计数）。

## 1. 契约（packages/api/src/contract.ts）

- [ ] Zod schema：`noteListItem`、`noteDetail`（spec §2.5 字段）
- [ ] oRPC contract：
  - `notes.list({ cursor?: string, limit?: number(≤20, 默认10) })` → `{ items: NoteListItem[], nextCursor: string | null }`
  - `notes.get({ id: string })` → `NoteDetail`
  - `health()` → `{ ok: true }`（或直接 HTTP `GET /`）
- [ ] `packages/api/src/index.ts` 导出 contract 与类型；`bun run check-types` 通过

## 2. Server 实现（apps/server/src/rpc/）

- [ ] `router.ts`：实现 `notes.list`（分页：cursor 传上一页最后一条 `id` 字符串，`WHERE id < :cursor ORDER BY id DESC LIMIT n+1`，多取 1 判断有无下一页）、`notes.get`（join author 昵称；`likeCount = count(*)`；`viewerHasLiked` 需会话时查询）
- [ ] 挂载：`app.use("/rpc/*", rpcHandler(...))`（oRPC Hono handler，带 better-auth 会话注入中间件）
- [ ] 验证：`alchemy dev` 下 curl `/rpc/notes.list`（GET/POST）返回种子列表与 nextCursor；非法 cursor 返回 400

## 3. Native 数据层（沿用 native-data-fetch Skill）

- [ ] `apps/native/lib/orpc.ts`：oRPC 客户端（fetch，指向 `EXPO_PUBLIC_SERVER_URL/rpc`，10s 超时）
- [ ] `apps/native/features/home/queries.ts`：`useNotesList`（query key 稳定，infiniteQuery：cursor 分页、onEndReached 拉取、加载更多态/错误重试）
- [ ] `apps/native/app/(tabs)/index.tsx`：双列瀑布流（FlatList `numColumns={2}` + 封面 3:4 比例）+ 无限滚动 + loading/空态/错误态（中文）
- [ ] `apps/native/app/note/[id].tsx`：详情页（大图、标题、作者昵称、正文、标签轻展示、赞计数只读展示，暂不交互）；未登录可看（AC-02）

## 4. 验证

- [ ] Web/模拟器：首页双列流、上拉加载更多（种子 ≥ 1.5 页）、详情数据全部来自 API
- [ ] 详情 `viewerHasLiked` 未登录为 false，计数正确
- [ ] `bunx expo install --check`；`bun run check-types`；scoped Biome
