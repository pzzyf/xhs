# P2：better-auth 注册登录登出 + Native 会话

> 目标：服务端 `/api/auth/*` 可用；Native 可注册（邮箱+密码+昵称）、登录、登出；未登录可进首页壳；登录成功回首页。
> 结束标志：模拟器/Web 上注册→登录→登出全流程可用；未登录浏览首页正常。

## 1. 服务端鉴权（packages/auth + apps/server）

- [ ] `packages/auth/src/auth.ts`：better-auth（`BETTER_AUTH_SECRET`、`BETTER_AUTH_URL`），Drizzle adapter + D1 `DB` 绑定，`additionalFields: { name: string }`（昵称注册时写入），basePath `/api/auth`
- [ ] better-auth 核心表与 Drizzle schema 对齐（P1 已建，核对列名：session/account/verification 必填列）
- [ ] `apps/server/src/app.ts`：挂载 `auth.handler`（`app.on(["GET","POST"], "/api/auth/*", ...)`）
- [ ] 验证：`alchemy dev` 下 `POST /api/auth/sign-up/email`（含 name）、`POST /api/auth/sign-in/email`、`GET /api/auth/get-session` 返回会话

## 2. Native 会话

- [ ] `packages/env/src/native.ts`：`EXPO_PUBLIC_SERVER_URL`（默认 localhost:3000；Android 10.0.2.2）
- [ ] `apps/native/lib/auth-client.ts`：`@better-auth/expo` 客户端，baseURL = `EXPO_PUBLIC_SERVER_URL`，SecureStore 持久化 token
- [ ] `apps/native/app/_layout.tsx`：Query → Gesture → SafeArea → Keyboard → HeroUI → Toast → AuthProvider → Theme → Router（BRIEF §5 根层级）
- [ ] `apps/native/features/auth/`：`auth-provider.tsx`（useSession 包装，暴露 user/signOut/session 刷新）、`auth-gate.tsx`（仅未登录访问需身份页时引导；不整 app 墙）
- [ ] `apps/native/app/sign-in.tsx`：登录/注册表单（邮箱+密码；注册含昵称）；成功 `router.replace("/")`（REQ-17）
- [ ] `apps/native/app/(tabs)/index.tsx`：首页壳（标题 + 「发布」入口按钮 + 空态占位），未登录可访问（AC-07）

## 3. 验证

- [ ] Web：注册→登录→会话持久→登出；刷新后仍登录
- [ ] 未登录直接进 `/` 正常（无强制登录墙）
- [ ] `bunx expo install --check`；`bun run check-types`；scoped Biome
