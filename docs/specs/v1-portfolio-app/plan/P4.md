# P4：R2 上传 + notes.create + 发布页

> 目标：客户端选图→压缩→PUT 上传 R2→`notes.create` 提交元数据；发布后信息流与「我的」可见；上传失败 Toast 可重试。
> 结束标志：已登录发布新笔记（单图），首页信息流可见，图片来自 R2（`/images/:key`）。

## 1. Server 上传（apps/server/src/app.ts 或独立 upload.ts）

- [x] `PUT /api/images`：鉴权（better-auth 会话）；读取 body 二进制（Content-Type 校验 image/*）；生成 `imageKey`（`notes/<uuid>.<ext>` 或时间戳方案）；写 R2 `IMAGES`；返回 `{ imageKey, imageUrl: "/images/<key>" }`
- [x] `GET /images/:key`：从 R2 读对象返回（Content-Type 从对象元数据），不存在 404（P3 已实现）
- [x] 验证：`alchemy dev` 下带会话 PUT 小图 → 返回 key；`GET /images/<key>` 200 且 Content-Type 正确；无会话 401
