# P1：Alchemy 资源 + Drizzle Schema/Migrate/Seed

> 目标：`alchemy dev` 本地起 Worker+D1+R2；`GET /` 健康检查可访问；Drizzle schema 生成迁移并应用；种子数据写入，首页开箱有内容（数据层先行）。
> 结束标志：本地 `alchemy dev` 健康检查 200；本地 D1 有 users/notes/likes 表；种子笔记 ≥ 16 条。

## 1. 资源声明（packages/infra/alchemy.run.ts）

- [ ] D1 `xhs-d1`（绑定名 `DB`，`migrationsDir: "./packages/db/migrations"`）
- [ ] R2 `xhs-images`（绑定名 `IMAGES`）
- [ ] Worker `xhs-server`（`main: "../../apps/server/src/worker.ts"`，dev port 3000）
- [ ] env：`BETTER_AUTH_SECRET`、`BETTER_AUTH_URL`、`CORS_ORIGIN`/`CORS_ORIGINS`、`SEED_SECRET`
- [ ] `packages/infra/.env.example` 与 `apps/server/.env.example` 写入示例（真密钥不入库）

## 2. Drizzle（packages/db）

- [ ] `package.json`：`drizzle-orm`（依赖）、`drizzle-kit`（dev）
- [ ] `src/schema.ts`：users/session/account/verification（better-auth 核心表）+ notes + likes（见 spec §3）
- [ ] `drizzle.config.ts`：dialect sqlite、schema 路径、migrations 输出到 `packages/db/migrations`（drizzle-kit 生成 SQL，Alchemy 应用，注意 drizzle 默认输出目录与 Alchemy migrationsDir 一致）
- [ ] `bunx drizzle-kit generate` 生成首个迁移 SQL
- [ ] 本地验证迁移：`alchemy dev` 启动后 D1 表存在（通过健康检查或临时查询）

## 3. Worker 壳（apps/server）

- [ ] `src/app.ts`：Hono app，logger + CORS（localhost/私网 + 配置源）+ `GET /` 返回 `{ ok: true, name: "xhs-server", time }`
- [ ] `src/worker.ts`：`export default { fetch: app.fetch }`，env 类型 `WorkerEnv = Cloudflare.InferEnv<typeof Worker>`（从 infra 导出类型）

## 4. Seed（packages/db/src/seed.ts）

- [ ] 生成/放置无版权占位图（本地生成渐变 PNG，不依赖外网图源）
- [ ] 种子：体验账号 `demo@xhs.dev` + 昵称；16 条中文笔记（标题/正文/标签 2-4 个/图片），时间倒序错开
- [ ] 种子写入方式：`POST /api/dev/seed`（`SEED_SECRET` 匹配才挂载）或本地脚本直连 D1+R2（按 Alchemy 本地能力定案）；幂等（已存在则跳过）
- [ ] 验证：本地 D1 查询 users/notes 行数符合预期

## 5. 验证

- [ ] `alchemy dev` 临时端口 `GET /` → 200 `{ ok: true }`
- [ ] 本地 D1 `notes` ≥ 16 行、`users` 含种子账号
- [ ] `bun run check-types` + scoped Biome

## 6. 阶段收尾

- 汇报：资源声明、迁移 SQL、种子数据、健康检查输出。
- 状态：awaiting-human-review。
