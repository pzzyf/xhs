# P7：公网部署 + 线上验收 + 文档收尾

> 目标：Alchemy 部署 Worker+D1+R2 到公网；Native `EXPO_PUBLIC_SERVER_URL` 指向线上；按 requirements §4 剧本全量验收；README 演示说明。
> 结束标志：DoD——公网 Workers + iOS/Android 模拟器连线上 API 走通 §2 剧本；开箱有种子内容。

## 1. 部署（BRIEF §7 约束）

- [ ] `packages/infra/.env` 配真 Cloudflare 凭据（用户授权；不入库）
- [ ] `apps/server/.env` 配线上 `BETTER_AUTH_URL`（部署 URL）、`SEED_SECRET`、CORS 源（如需 web）
- [ ] `bun run alchemy:plan` → 确认资源变更 → `bun run alchemy:deploy`
- [ ] 线上 `GET /` 健康检查 200（公网可达，AC-10）
- [ ] 线上跑 seed（`POST /api/dev/seed` 带 SEED_SECRET，或部署后脚本），确认开箱有种子内容（AC-19）

## 2. Native 连线上

- [ ] `apps/native/.env`：`EXPO_PUBLIC_SERVER_URL=<部署 URL>`（不入库；`.env.example` 更新注释）
- [ ] iOS 模拟器 + Android 模拟器均指向线上 API（AC-03）

## 3. 全量验收（requirements §4 剧本 AC-01…AC-10）

- [ ] AC-01：冷启动未登录 → 首页种子双列流 → 上拉加载更多
- [ ] AC-02：详情大图/标题/正文/作者/赞计数（未登录）
- [ ] AC-03：未登录点赞 → 登录页
- [ ] AC-04：注册（邮箱+密码+昵称）→ 回首页
- [ ] AC-05：同一详情点赞 +1/取消 -1/赞态正确
- [ ] AC-06：发布单图 → 信息流/我的可见，图来自 R2
- [ ] AC-07：上传失败 Toast → 可重试
- [ ] AC-08：我的（默认头像+昵称+我的笔记）→ 可进详情
- [ ] AC-09：设置退出 → 可继续浏览，写操作再要求登录
- [ ] AC-10：`GET /` 公网可达；EXPO_PUBLIC_SERVER_URL 指向该部署
- 验收方式：iOS 或 Android 至少一端完整录证（模拟器 + 线上 API），另一端能启动并打到同一 API
