# 双列瀑布流 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将首页和「我的」页面改为两列高度不一的 Masonry 瀑布流，并让卡片封面使用图片自身比例。

**Architecture:** 使用 `@shopify/flash-list` v2 的 `FlashList`，通过 `masonry` 与 `numColumns={2}` 开启瀑布流；列表仍消费现有分页查询，不改 API。`NoteCard` 内部异步读取远程图片尺寸，以稳定的 `3:4` 比例作为首帧兜底，再将实际宽高比传给图片布局。

**Tech Stack:** Expo 57、React Native 0.86、TypeScript、`@shopify/flash-list` v2、React Native `Image.getSize`、Biome、TypeScript。

## Global Constraints

- 使用 Bun 作为唯一包管理器；不手改 lock 文件。
- UI 文案仅中文。
- 不改 API、数据库、鉴权和分页数据结构。
- 不自动 commit、push 或部署。
- 修改客户端后运行 `bun run check-types`。
- 保持现有主题 token、卡片点击路由、加载/错误/空态和分页行为。

	test("returns the image width-to-height ratio", () => {
		expect(getCoverAspectRatio(1200, 800)).toBe(1.5);

- [ ] **Step 3: Implement the minimal ratio helper**

Create `apps/native/components/note-card-ratio.ts`:

```ts
export const DEFAULT_NOTE_COVER_RATIO = 3 / 4;

export function getCoverAspectRatio(width: number, height: number) {
	return Number.isFinite(width) && Number.isFinite(height) && width > 0 && height > 0
		? width / height
		: DEFAULT_NOTE_COVER_RATIO;
}
```
